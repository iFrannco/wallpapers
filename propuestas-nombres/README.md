# Registro de nombres de los wallpapers

Los 332 nombres aprobados se aplicaron el 25 de octubre de 2026. Solo se cambiaron los nombres de los archivos: su contenido y sus extensiones se conservaron. Se verificó la integridad de cada imagen mediante SHA-256.

Los nombres usan minúsculas, guiones y caracteres sin tildes. Describen el contenido, los colores o la composición y conservan la extensión de cada archivo. Las referencias a personajes se usan cuando resultan reconocibles.

Cada número coincide con el de las láminas, que conservan los nombres anteriores como referencia. La tabla muestra los nombres anteriores y nuevos; sus enlaces abren las imágenes renombradas. La [tabla CSV](nombres.csv) conserva el mapeo aprobado: `nombre_actual` corresponde al nombre anterior y `nombre_propuesto` al nombre aplicado.

Los 332 nombres nuevos son únicos.
